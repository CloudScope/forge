01 Request path

  1. Browser → API Gateway → Lambda. ANY / and ANY /{proxy+} both target the same function, so the HTML page and every /api/* call are one integration.
  2. Upload starts an execution. The Lambda calls StartExecution and returns immediately — it never runs a workflow.
  3. RunSegment launches a Fargate task that ticks the engine until it reaches a human gate.
  4. CheckWorkflowState reads the stored status. If PAUSED, AwaitApproval registers a task token and the execution parks — at zero cost, for as long as it waits.
  5. The operator answers the gate. The API records the decision durably first, then releases the token; ResumeSegment launches the next task.
  6. Repeat until terminal. Artifacts land in S3; the Studio reads them back and can package the whole run as a .zip.

02 Why these services

Each choice trades against an obvious alternative.
ChoiceReason
Lambda + Web AdapterRuns uvicorn main:app unmodified — the same image runs locally with docker run. Scales to zero between visits.
Step FunctionswaitForTaskToken parks a run at a human gate at no cost, however long the human takes.
ECS on FargateA segment needs minutes and a writable filesystem for codegen. Lambda's 15-minute ceiling and read-only filesystem do not fit.
DynamoDB + S3No idle cost, and the workload is key-lookup documents plus blobs — not relational.
Parameter StoreStandard parameters are free; nothing here needs the managed rotation Secrets Manager charges for.
No NAT gatewayA NAT would cost more than every other line item combined. Tasks take a public IP behind an egress-only security group.

04 The SDLC pipeline and its gates

Gates marked always pause for a human even in demo mode. A failing blocking gate does not merely stop the run — it triggers the compensation saga, so a half-validated tree is never left behind as a deliverable.
